Live chat — real Supabase build

The real chat, loaded the way the CMS will load it — one <div data-bmtv-chat> and one <script src="/chat/bmtv-chat.js">. Messages you send here hit the real database and appear for anyone else with the page open.

Testing the full path

  1. Pick a name and post a message here. It saves with status live — visible on the site, not on air.
  2. Open the moderator panel in a second tab and sign in with a moderator email account.
  3. Release the message. It now shows released here and reaches the overlay.
  4. Open the vMix overlay — released messages only. This is what a vMix Browser input renders.
  5. For vMix Social instead, run python irc-bridge.py in bmtv-chat/ and point vMix at 127.0.0.1:6667, channel #bmtv.
Moderators must use email accounts, not anonymous. An anonymous identity lives in browser storage — clearing cookies or switching machines mints a new user_id and silently loses moderator access. Add one with insert into public.moderators (user_id, note) values (...).
