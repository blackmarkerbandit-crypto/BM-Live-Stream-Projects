1 · Find archived media

Reads the real Active / Archived status of every file in your ChannelCast library — the status you set in the dashboard, which this app couldn’t see before. Takes about two minutes.

2 · Purge from loops

Re-reads all 28 loops live, audits each against every rule, then plans the fix. Two ways to fix a loop — pick per loop, the recommended one is preselected:

  • Surgical — cut out just the archived items and top the loop back up to 6h. A few calls per loop instead of a few hundred. Everything else stays exactly as it is. The one cost is drift: pulling a 30-second promo out of the middle shifts everything after it 30 seconds earlier, so an artist pair sitting right on the 2h line can land a few seconds under it. The exact worst case is shown per loop.
  • Full rebuild — regenerate the whole loop from scratch. Exact on every rule, but it reshuffles all the music and takes ~60× longer.
