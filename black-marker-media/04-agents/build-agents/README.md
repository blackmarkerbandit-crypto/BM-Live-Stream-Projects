# Build Agents

Agents that build and maintain BMB's internal tools and software: the ChannelCast loop builder, clip-agent, site builds (3.0, corporate site), automation scripts.

Added alongside the original three categories (`research-agents/`, `marketing-agents/`, `ops-agents/`) because BMB's tooling surface (loop builder, clip-agent, ATEM flypack, live-chat-widget) is real engineering work that doesn't fit "reporting, follow-ups, tracking."
